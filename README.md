# Daily 5

レベルに合った「今日の5フレーズ」が毎日出る、自分用の英語学習アプリ。
就活・ビジネス・学術・金融・IT の英語を約300件収録（5レベル × 60件）。

## 使い方
- 初回はレベルチェック（23問・約2分）。存在しないフレーズが3つ混ざっているので正直に答える。
- 毎日5件：期限が来た復習（最大2件）＋今のレベルの新しいフレーズ。
- 「わかった」→ 3日後 → 7日後 → 21日後に再出題、21日後も「わかった」で習得済み。「まだ」→ 翌日。
- 今のレベルで3日続けて新しいフレーズの8割以上が「わかった」なら、レベルアップを提案。

| キー | 動作 |
|---|---|
| Space | 意味を見る |
| → / ← | わかった / まだ |
| S | 発音 |
| 1 / 2 / 3 | レベルチェックの回答 |

## ローカルで開く
```sh
cd "~/Desktop/Vocab Anki"
python3 -m http.server 8000
# → http://localhost:8000
```
`index.html` をダブルクリックで直接開いても動く。

テスト用に日付をずらしたいときは `http://localhost:8000/?debug` で開いて「設定」の一番下を使う。

## データ
- 学習記録はブラウザの localStorage に保存（端末ごとに別々）。
- パソコン ↔ スマホで移すときは「設定 → 書き出す」で .json を作り、もう一方で「読み込む」。

## フレーズを足す
`phrases.js` の好きなレベルの配列に1行追加：
```js
["英語", "word か phrase", "jobhunt/business/academic/finance/tech", "意味", "例文", "例文の訳"],
```
英語の文字列がそのままIDになるので、同じ英語を2回入れないこと。

## GitHub Pages で公開
1. GitHub で新しいリポジトリ（例：`vocab-anki`）を作る
2. このフォルダを push
3. リポジトリの Settings → Pages → Branch を `main` / `(root)` にして Save
4. `https://<ユーザー名>.github.io/vocab-anki/` で開ける。iPhone は Safari の共有ボタン →「ホーム画面に追加」
