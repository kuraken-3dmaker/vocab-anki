# Daily 5

レベルに合った表現を毎日5つずつ覚え、確認問題と作文で定着させる自分用の英語学習アプリ（1日10〜15分）。
就活・ビジネス・学術・金融・IT の英語を約300件収録（5レベル × 60件）。

## 1日の流れ
1. **確認問題**（最大8問）：前に覚えた表現が、決まった間隔で戻ってくる。覚え始めは4択、覚えてきたら例文の穴埋めを自分で入力
2. **新しい5つ**：カードで意味と例文を確認し、「知ってた / 初めて」を選ぶ
3. **穴埋め**：今日の5つを例文の空欄に入力
4. **作文**（2問）：場面のお題に合わせて、その表現を使った英文を書く
5. **まとめ**：正答率、間違えた表現、今日の作文

間違えた問題はその日のうちに最後にもう一度出る。

## 復習の間隔
正解するたびに 1日 → 3日 → 7日 → 16日 → 35日後 と間隔をあけて出題し、35日後にも正解したら習得済み。
間違えたら翌日からやり直し。期限が来たものが少ない日は、しばらく見ていない表現を早めに出す（早めの復習では段階は上がらない）。

## 作文の添削（大学の claude.ai）
「Claude で添削」を押すと、添削の依頼文が入った状態で claude.ai が新しいタブで開く（依頼文はクリップボードにもコピーされる）。
添削を読んだら、アプリに戻って「うまく使えた / いまいち」を押す。直された文は「添削メモ」に貼っておくと「作文帳」で見返せる。
API キーは使わないので、アプリから外部への通信はない。

## キー操作
| 場面 | キー | 動作 |
|---|---|---|
| 新しい5つ | Space / ← / → | 意味を見る / 初めて / 知ってた |
| 4択 | 1〜4 | 選ぶ |
| 穴埋め | Enter | 答える |
| 答えの後 | Enter | 次へ |
| 作文 | ⌘ Enter | Claude で添削 |
| どこでも | S | 発音（穴埋めの答える前を除く） |

## ローカルで開く
```sh
cd "~/Desktop/Vocab Anki"
python3 -m http.server 8000
# → http://localhost:8000
```
テスト用に日付をずらしたいときは `http://localhost:8000/?debug` で開いて「設定」の一番下を使う。

## データ
- 学習記録と作文帳はブラウザの localStorage に保存（端末ごとに別々）。
- パソコン ↔ スマホで移すときは「設定 → 書き出す」で .json を作り、もう一方で「読み込む」。
- 旧バージョン（カードだけの版）のデータは自動で引き継がれる。

## フレーズを足す
`phrases.js` の好きなレベルの配列に1行追加：
```js
["英語", "word か phrase", "jobhunt/business/academic/finance/tech", "意味", "例文", "例文の訳"],
```
- 英語の文字列がそのままIDになるので、同じ英語を2回入れないこと。
- 例文には見出しの表現をそのまま（活用は可）入れること。穴埋め問題の空欄になる。

## ファイル
| ファイル | 中身 |
|---|---|
| `phrases.js` | 教材データ |
| `quiz.js` | 穴埋めの空欄づくり、答えの判定、4択 |
| `coach.js` | 作文のお題と、claude.ai への依頼文 |
| `app.js` | セッションの流れ、復習の間隔、保存、表示 |
